# trisk-crm-sync

Двостороння синхронізація WooCommerce з KeyCRM (замовлення, статуси, оплати, залишки, ціни) та Telegram-бот для менеджерів.

## Обмеження: акційна ціна

Окремого поля знижки в KeyCRM немає, тому акційна ціна на сайті визначається порівнянням ціни оффера з KeyCRM
із базовою ціною `_trisk_crm_base_regular_price`, яку плагін зберігає для кожного товару чи варіації:

- ціна з CRM нижча за базову — на сайті звичайна ціна лишається базовою, а ціна з CRM стає акційною (`sale_price`);
- ціна з CRM дорівнює базовій або вища — вона стає новою звичайною ціною, акція знімається, базова ціна оновлюється.

Наслідки:

- постійне зниження ціни в KeyCRM завжди показується на сайті як акція (із закресленою старою ціною);
- щоб справді знизити звичайну ціну, треба оновити базову ціну на сайті (змінити звичайну ціну й `_trisk_crm_base_regular_price`),
  інакше наступна щогодинна синхронізація поверне акцію;
- якщо потрібна окрема знижка, варто перейти на спеціальне поле знижки в KeyCRM.

## Вебхуки

- KeyCRM не вміє надсилати заголовки, тому токен вебхука KeyCRM передається в query string (`?token=`) — він потрапляє в журнали веб-сервера.
  Також приймаються заголовки `X-Trisk-Token` та `Authorization: Bearer`.
- Вебхук Telegram приймає секрет лише в заголовку `X-Telegram-Bot-Api-Secret-Token`.
- Статус з KeyCRM, якого немає в таблиці відповідності (Налаштування → «Відповідність статусів»), ігнорується:
  замовлення не змінюється, подія пишеться в журнал зі статусом «Пропущено».
